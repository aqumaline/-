# Росток — интернет-магазин наборов для микрозелени

Статический сайт на HTML5, CSS3 и Vanilla JS. Серверная часть не нужна.

## Возможности
- Каталог с поиском, категориями и сортировкой
- Корзина (сохраняется в браузере), оформление заказа с валидацией
- Форма обратной связи с проверкой полей, уведомления, FAQ, мобильное меню
- Адаптивная вёрстка для телефонов, планшетов и компьютеров

## Структура
```
index.html
css/style.css
js/script.js
images/ (favicon.svg, hero.svg)
README.md
.gitignore
```

## Запуск локально
Распакуйте архив и откройте `index.html` в браузере.

## Публикация на GitHub Pages
1. Создайте новый репозиторий на github.com (например, `rostok`).
2. Нажмите **Add file → Upload files** и загрузите все файлы проекта (папки `css`, `js`, `images` и файл `index.html` должны лежать в корне репозитория).
3. Нажмите **Commit changes**.
4. Откройте **Settings → Pages**. В разделе *Build and deployment* выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем **Save**.
5. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/rostok/`.

## Что изменить под себя
Товары: массив `PRODUCTS` в `js/script.js`. Контакты и тексты: `index.html`. Цвета: переменные в начале `css/style.css`.

Шрифты (Onest, Unbounded) подключаются с Google Fonts, при отсутствии интернета используется системный шрифт.
